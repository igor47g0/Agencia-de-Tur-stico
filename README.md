## 📌 Sobre o Projeto

Este projeto é um portal de desenvolvimento moderno voltado para experiências de viagem, orçamentos personalizados e conexões exclusivas.

### 🛠️ Tecnologias Utilizadas
* **Frontend:** HTML5, CSS3, JavaScript (ES6+), Bootstrap 5
* **Backend & Banco de Dados:** Java / Spring Boot, MySQL
* **Estilização:** Visual Dark Theme com toques de Dourado

---

## ⚙️ Configuração do Ambiente e Banco de Dados

> ⚠️ **Atenção:** Por razões de segurança, as credenciais de acesso ao banco de dados foram omitidas deste documento.

Para executar o projeto localmente, crie um arquivo `.env` na raiz do seu projeto (ou configure as variáveis no seu `application.properties` / `application.yml`) utilizando o modelo abaixo:

```env
# Configurações do Banco de Dados
DB_URL=jdbc:mysql://localhost:3306/seu_banco_de_dados?useSSL=false&serverTimezone=UTC
DB_USER=SEU_USUARIO_AQUI
DB_PASSWORD=SUA_SENHA_AQUI
